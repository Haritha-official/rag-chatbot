# Expense Tracker

A browser-based expense tracker built with HTML, CSS, and JavaScript.

## Features

Users can log both income and expenses, and the app compares actual
spending against a set budget. There's also a savings goal progress
tracker that shows how close the user is to a target amount.

## Data persistence

Since this project doesn't use a backend, all data is saved using the
browser's localStorage, meaning a user's entries persist even after
closing and reopening the browser, as long as they use the same browser
and device.

## Responsive design

The layout is responsive, adapting to different screen sizes so the
tracker is usable on both desktop and mobile devices.
